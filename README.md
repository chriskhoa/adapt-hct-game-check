# Word Game Puzzle Size Checker

A simple web app tool for internal team use to check if quotes will fit in word game puzzle sizes.

## Features

- Enter quotes manually or upload from a text file
- Configure multiple puzzle sizes (e.g., 8x8, 10x10, etc.)
- Check if quotes fit within the specified puzzle dimensions
- Clean, responsive UI built with Ant Design

## Tech Stack

- React 19
- Vite
- Ant Design
- JavaScript

## Development

Install dependencies:
```bash
npm install
```

Run the development server:
```bash
npm run dev
```

Build for production:
```bash
npm run build
```

## Deployment to GitHub Pages

1. Make sure your repository is pushed to GitHub
2. Run the deploy command:
```bash
npm run deploy
```

3. Go to your repository settings on GitHub
4. Navigate to Settings > Pages
5. Under "Source", select "gh-pages" branch
6. Your app will be available at: `https://[your-username].github.io/adapt-hct-game-check/`

## Usage

1. Enter your quote(s) in the text area or upload a text file
2. Configure the puzzle sizes you want to check against
3. Click "Check" to verify if the quote fits in the puzzle dimensions
4. View the results in the output section
